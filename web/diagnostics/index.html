读取 FM-1 的实际性能

适用 0.4.7-rc2 及更新版本。接上 USB，用 Chrome 或 Edge 连接 MIDI 输入与输出。正常启动后可采集性能；USB RESCUE 中也可读取启动信息。原始 0.4.6-rc2 恢复包不支持此诊断协议。

0.4.7-rc2 的 DSP 为各前台片段耗时之和，IRQ 为 DMA 复制与 USB 供数；XRUN 表示 DSP 块耗时超预算，UND 表示输出缺块，CLIP 表示数值触顶。上次运行阶段及异常记录可能来自更早的运行，应结合报告中的版本与重启来源判断。
