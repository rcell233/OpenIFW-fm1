0.4.7-rc8 DSP 内核优化候选

对原非线性函数使用精确倒数与余数校正，全部 42.9 亿个 int32 输入与原结果一致；波形按实际需要的输出执行同一公式，减少通用分支和参数搬运。选择 Install 0.4.7-rc8。测试与性能边界

0.4.7-rc7 CPU 优化候选

第三滤波器按原顺序处理每一级；包络和 LFO 仍按原采样时序运行，只复用输入未变化的速率系数。音色、单音、Legato、Q23 混响和最终输出增益保留。选择 Install 0.4.7-rc7。测试与性能边界

0.4.7-rc5 混响降噪参考

混响延迟与反馈由 Q15 提升到 Q23，保留原空间结构、Size / Width 和湿干控制。最终约 6 dB 输出增益、MASTER 曲线和 DAC 余量保留。核心合成、单音、Legato 和出厂音色参数保持原值。直接选择 Install 0.4.7-rc5。改动与测试结果

更新后验证声音与性能

进入 GLO 的 PERFORMANCE 页，或长按 HOME → SYS → PERFORMANCE。向右转第二旋钮 RESET，持续演奏并观察 DSP MAX / XRUN / DMA / UND；后三项应保持 0。IRQ 包含 DMA 复制与 USB tap；DSP 是各前台合成片段耗时之和。第一旋钮可选 SINE / MUTE 帮助排查输出链路，退出此页自动恢复 SYNTH。

USB RESCUE / 恢复设备

如果屏幕显示 OPENIFW FM1 USB RESCUE / CONNECT USB，保持此画面和 USB 连接，点击上方 Install 安装修复版；安装和重启时松开按键，尤其 OCT−。

可回退到 0.4.7-rc7（本轮内核优化前），或回退到 0.4.7-rc5（CPU 优化前，保留混响降噪及输出增益），或回退到 0.4.7-rc4（保留约 6 dB 输出增益，恢复之前的混响），或回退到 0.4.7-rc3（恢复原输出音量，保留半速混响优化），或选择更早的 0.4.7-rc2、0.4.6-rc2、0.4.4、0.4.1 恢复包。返回最新版安装。救援身份 FM-1_000 不会被当作正常安装成功；曾启动失败的 0.4.7-rc1 继续撤回。

连接失败或安装中断
  • 确认使用能传输数据的 USB 线，并关闭占用 FM-1 MIDI 的 DAW、编辑器或其他网页。
  • 如果连接了多台设备，请只保留要安装的那台 FM-1。
  • 如果设备仍停在兼容的升级模式，重新接上 USB 后点 Install，会恢复写入。
  • 如果当前固件无法正常启动，可尝试按住 OCT− 开机进入 USB 救援模式，再连接安装。
  • 如果浏览器拒绝 MIDI 权限，请在地址栏的站点设置中允许 MIDI，然后重试。

本页使用 FM-1 的 USB-MIDI 升级协议，只安装本项目发布的 OpenIFW 固件。只有型号确认通过的 FM-1 才会进入写入流程。
