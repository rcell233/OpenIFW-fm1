# rc16：定位 MIDI 延迟、滑音或音色差异

**rc17 的回放差异。** 机身 TRS 收到的 CC5（滑音时间）仅记录，不作用于演奏。USB MIDI 仍支持 CC5。.mid 保留原始消息但不区分输入端口；如在电脑通过 USB 复现机身听感，须按 JSON 的来源排除 TRS 的 CC5。

**接线与录制。** 电吹管 MIDI OUT 接 FM-1 MIDI IN。选好音色，松开全部音符，在 GLO → PERFORMANCE 短按 REC 开始。先用面板弹一段两个音的连音，再用吹管吹同一段，等相邻音都放开后再按 REC 停止。无需电脑；最多 4096 条消息或 120 秒。数据保存在 RAM，断电会丢失，开始下一次录制会覆盖。用 USB 供电时请在开始前就连接电脑，以免重接时掉电。

**导出。** 在桌面 Chrome / Edge 打开[设备诊断页](https://rcell233.github.io/OpenIFW-fm1/diagnostics/)，连接 MIDI 并允许 SysEx，选同一台 FM-1 的输入与输出（机身 USB 通常显示为 **Felucca**，不是电吹管），点击「读取 MIDI 录制」，下载 JSON 和 .mid。读取不会删除录制。JSON 可直接发给维护者。标准 MIDI 文件可导入 DAW，用原速度和通道发回相同音色的 FM-1；若含面板音符，其导出通道为 1，重放时可选 ALL。文件保留事件顺序与力度，时间单位为 0.5 ms。它不包含音色、录制前已按住的音符或设备初始 CC 状态。

**读不到时先保住这段录制。** 保持机身供电，不重刷、不重录；可以刷新网页。诊断页在能唯一识别 FM-1 端口时预选它们，有多个候选时让你选择。读录制时会核对固件的实际启动报告；如报告没有返回，仍会单独尝试录制协议。知道是旧固件、救援模式、两个查询都没有有效回复，或是已确认版本但某一页没有回复，这几种情况会显示不同提示。单页最多发送三次只读请求。反馈故障请复制完整提示，包含输入、输出名和失败页码（如有）。

**怎么看日志。** `start` 是录制开始时的音色编号、参数指纹、接收通道、气息映射、滑音设置等；`histogram` 可快速找出 CC5、Pitch bend 或多通道消息。每条消息保留分派时刻（`us`）、来源（TRS/USB/PANEL）、通道是否匹配、原始通道消息字节；包括零力度 Note On、面板按下与释放。已展开 running status；不捕获 MIDI 时钟、Active Sensing、SysEx 或线电平。文件不包含录音。若两份日志起始音色指纹不同，应先对齐音色再比较。

- `dmaNoticeToDispatchUs`：机身 TRS 消息的最后一个字节被固件轮询发现，到前台分派该消息。无法测量吹管内的扫描、串行发送时间或轮询前的等待。
- `dispatchToNextBlockUs`：从分派到固件开始渲染下一音频块。并非耳机口发声时刻；声卡输出已有缓冲。未观测到的间隔为 null，65534 表示该项达到 65.534 ms 的上限。
- `droppedTrsBytes`：录制期间串口积压超过安全余量时丢弃的字节数。通道不匹配的通道消息仍可查看；匹配不代表每一种消息都被合成器使用。

**代码与对照测试。** rc15 在 UART DMA 的一帧收到 32 个字节或发生空闲超时后取数；与面板路径相比，连续发 CC 时有额外的成批等待。在 31,250 baud、每字节 10 位下，32 字节为 10.24 ms；首字节等末字节的时间为 9.92 ms。rc16 门槛为 1 字节，仍用既有 2 kHz 定时轮询，前台有空时才分派。此计算不是端到端或实机测量。

在 `make trs-input-test` 中，以面板的原生力度 110 及相同的按放时刻、交叠和处理边界，在六个出厂音色比较面板与串口输入：230,400 帧立体声 PCM 和 900 个块的音高校验逐字节相同。另一个测试用 Tresure Island 保持 C4，连到 C5，单独改变 CC5，量到离目标小于 0.01 半音为止：CC5=0 时 105 帧（2.38 ms），CC5=127 时 2260 帧（51.25 ms），采样率 44,100 Hz。两项均为运行固件 C 代码的软件测量，并非用户吹管抓包或实机往返延迟。

rc16 取消未学习的 CC20–23 自动编辑当前页面，保留显式 MIDI Learn；按端口和通道隔离 NRPN，收到 RPN 选择即取消原 NRPN。保留音色定义的 CC5 滑音与弯音、按键力度及重叠换指行为。呼吸控制器新配置默认为 CC2；已保存的有效编号仍优先。如之前保存过 CC7，在 GLO → CONTROL 将 BR CC 设成 2，再长按 HOME → SYS → SAVE SETUP → OCT+。未收到所选 CC 时气息为满值，收到后保留最近一次输入（包括 0）。
