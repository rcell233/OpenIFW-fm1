# 0.4.5：连续操作与屏幕刷新

用户已确认 0.4.4 可以在设备启动，声音最接近网页 Demo，但仍有少量破音，UI 大约 1 fps。本版处理刷屏调度和绘图工作；实际设备帧率和剩余音频问题仍待验证。

## 安装

打开 [安装 0.4.5](https://rcell233.github.io/OpenIFW-fm1/install/?v=0.4.5)，确认按钮显示 **Install 0.4.5** 后安装。保持 USB 连接，安装与重启时松开全部按键，尤其 OCT−。

保留 [0.4.4 回退入口](https://rcell233.github.io/OpenIFW-fm1/install/?recovery=0.4.4&v=0.4.5)，使用用户已确认能启动的原始包，SHA 为 `39fb0338e9c12394897edd62b19902af1f82b324c03628ee102c7d8c9ec1af8e`。更早的 0.4.1 恢复包也继续保留。

## 已复现并修改的路径

- 旧版每次收到旋钮变化，就把正在进行的屏幕扫描重置到第一块，并丢弃全部行缓存。在持续变化期间，控件所在的后续行可能一直刷不到。现在合并新请求，完成当前扫描后处理下一轮；持续输入时仍能完成刷新，配色变化也会在后续扫描生效。
- 16 行绘图区原先仍解码块外的字体像素、重复创建颜色渐变，并逐像素执行背景坐标检查。现在先裁剪可见的字形行、缓存同色渐变、跳过完全块外的线条，并按行写入同样的石纹。
- LCD DMA 仍拥有当前像素缓冲时，绘图立即返回主循环，继续服务输入、USB 和看门狗；传输完成后才改写缓冲。保持原屏幕时钟和数据格式。
- 普通完整刷新请求保留有效行缓存；只有启动清屏或独立 OTA 画面等外部写屏才使缓存失效。相同完整画面不再重复发送 SPI 行。

原布局、字体、颜色、按钮操作含义保持不变。DSP、预设、调制矩阵、包络、单音 / Legato、音频中断、原平台代码和 XIP 链接脚本均未修改；没有重新引入 RAM DSP。

## 验证方法

新增 8,120 组独立的字体、线条和石纹逐像素对照，覆盖五种字体、四种配色和部分裁剪；57 页与原同步画面一致。连续 100 次旋钮变化时，旧版只能刷到第 16 行，完整扫描为 0 次；新版能完成至少 5 次。相同完整画面不产生额外像素传输。相关测试运行于 ASan / UBSan 并加入持续集成。

目标指令模型使用相同的 240 MHz、除法 48 周期假设和 SPI 线速等待，运行相同的 6.5 秒持续旋钮与演奏脚本。旧版最长完整刷新间隔为 **2,657 ms**；新版最长 **140 ms**，中位数 **58 ms**，两者音频 XRUN / DMA / YIELD 均为 0。它是运行真实编译指令的对照，**不是设备实测 FPS**；不模拟真实 cache、Flash 等待、总线争抢或连接的 USB 主机。

另外保留人为降低至 160 MHz 的过载模型对照，用来确认让出保护仍在运行；该设置不是设备 CPU 频率测量。在该故意过载场景中，旧 / 新版的 XRUN 均为 839、YIELD 均为 104；新版刷新间隔中位数从 755 ms 降至 175 ms，但最长仍为 814 ms，说明 UI 优化没有消除持续的 DSP 过载。桌面绘图计时只用于相对比较，不能换算为 FM-1 占用或帧率。

## 剩余破音与设备读数

本版不修改音频中断或合成计算，不能把 UI 改善当作破音已消失的证明。持续过载仍会让出 DSP 并重复旧音频块；模拟音频链路、输出削波及 USB 并发也尚未实体测量。

PERFORMANCE 新增 **MAIN**（应用主循环最大服务间隔，ms）与 **YIELD**（过载保护让出次数）；K2 RESET 同时清零这两项。XRUN / DMA / YIELD 持续增长表明存在实时负载问题；CLIP 增长提供输出限幅线索。MAIN 不是 LCD 帧率。网页继续显示 DEVICE ONLY，不把主机计时冒充芯片读数。

安装后先检查持续转旋钮时数值区域能否更新，再边演奏边操作。若仍有破音，RESET 后演奏几秒，记录 PERFORMANCE 页，比较 SINE / SYNTH；步骤见 [上板测试](HARDWARE_TEST.md)。

最终 UI / 安装器与完整引擎回归、ASan / UBSan 均通过。166 个场景的 332 份冻结 PCM / 状态和 12 组冻结 WASM 演奏（1,228,800 个立体声帧）保持原值；安装器 93 项检查含 0.4.4 原包从救援身份完整回退。正常 / OCT− 救援启动、最重工厂预设的 4.5 秒目标运行以及 24 个目标 IRQ 黄金校验值通过。

发布包为 **610,110 B**，应用 **225,768 B**，data+bss **31,888 B**，pool **294,216 B**；原 Flash driver RAM 代码 **2,848 B**，RAM DSP 为 0。SHA-256：`403c6e3efa81760703c29339d5a4fa758b59775505327001b4da66b70e4cc536`。
