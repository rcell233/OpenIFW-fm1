# Tresure Island：上游与 FM-1 的同输入对照

比较对象是上游 OpenIFW 1.3.1（`e8339dab2cee475b9884effbc9c6c906e5b96099`）与 rc17/rc18 的 C 应用及固定点 DSP。用实机录制的 JSON 检查音色指纹（1355846903）、初始呼吸（CC2=0、直线）和来源（TRS）。再用同一段标准 MIDI 检查时间和消息：4,015 条逐条一致，MIDI 的时间误差不超过导出导入分辨率的半个刻度（0.25 ms）。公开仓库不包含录制本身。

## 输入与听感要分开测

- 上游网页实际默认呼吸是 CC7，连接后先设置气息为 0；这段录制只有 CC2/34，没有 CC7。使用上游默认设置重放为静音。上游用 CC2 并保留默认 CC5 时则有声，但会响应录制的 39 条 CC5。FM-1 延续 rc17：气息 CC2，机身 TRS 的 CC5 只录制，不生效；USB 的 CC5 仍生效。
- 以下同输入比较把上游设置为 CC2，并不把 CC5 送给它。两边均用 44.1 kHz、同一事件时点及顺序，对比锁定在同一合成器采样边界。生产浏览器原生是 48 kHz，性能、缓冲、采样率转换及声卡模拟级都另计；不同采样率不能按数组索引直接做逐样本比较。
- rc17 实机记录无串口丢字节。30 个 Note On，从 UART 轮询发现末字节到开始渲染：中位 2.172 ms，最大 7.035 ms。这个窗口不包含吹管扫描、串行传输、轮询前的等待或模拟输出。
- rc18 在已有的每 32 帧渲染前执行排队消息，避免同一块已经开始生成时仍等到下一个 256 帧块。采样时间线上，边界间距由 5.805 ms 降到 0.726 ms，最迟可少等 224 个采样（5.079 ms）。这不是实机总延迟保证：原有的 256 帧 DMA 和两块队列水位仍保留，以防断音。新版日志使用 `dispatchToNextSliceUs`，老日志使用 `dispatchToNextBlockUs`。

## 同事件的音频对照

比较的是 MASTER、DAC 和外部声卡之前的数字合成器输出，未做逐段音量归一化或时间平移。下表为 32 帧对齐结果。

| 路径 | FM-1 总 RMS 相对上游 | 样本差值 RMS（满幅为 1） | 发声段 10 ms 响度差的 95 百分位 |
| --- | ---: | ---: | ---: |
| Dry：关闭相位、合唱、两组延迟与混响，保留音色的激励与 EQ | −0.00013 dB | 0.000322 | 0.004 dB |
| 只关闭混响 | −0.0065 dB | 0.000336 | 0.153 dB |
| 出厂效果全开 | −0.567 dB | 0.01056 | 4.629 dB |

Dry 波形的差值比上游信号 RMS 低 34.21 dB，单样本最大差 0.00632（约为满幅的 0.63%）。加 Hann 窗后按频带积分，250 Hz–8 kHz 内的 5 个分段最大差约 0.002 dB（在 20–100 Hz 为 0.157 dB）；逐个音符的发声/松音 gate 和单音栈没有样本不一致。Q31 门控最大差约 0.00000061，四个包络最大差 0.00000131，含弯音的控制音高最大差 0.0062 音分。这是同采样率下的近似，不是浮点和定点输出逐位相同。

只关混响时，主频带 250 Hz–8 kHz 内分段最大差约 0.057 dB；延迟线仍在 22.05 kHz，16 kHz 以上的弱尾部变化更明显。出厂效果下听感差距主要在混响（FM-1 使用半采样率的共享混响，保留原出厂参数）。本次没有改音色、振荡器、包络、混响，或用静态 EQ/响度校正掩盖差异。

另按原始消息时刻在上游 48 kHz 渲染干声，再重采样到 44.1 kHz 与板端比较：总 RMS 差约 −0.005 dB，250 Hz–8 kHz 分段最大差约 0.20 dB，20–250 Hz 弱频带最大约 0.77 dB。这项把采样率及入样时机放在一起比较，适合看母带能量，不能替代同采样时钟的逐点误差。

## 重现

在有上游 1.3.1 checkout 和原始两份录制的本地运行：

```sh
make build/take-parity
node tests/take_parity.mjs recording.json recording.mid ../upstream-openifw
python3 tools/measure_take_parity.py recording.json
```

第三步使用 NumPy/SciPy。它同时提供上游 48 kHz 无事件量化的干声结果，重采样后作能量诊断。生产硬件实时 CPU、任意其他音色与外接 DAC 的端到端测量不在此报告范围。
