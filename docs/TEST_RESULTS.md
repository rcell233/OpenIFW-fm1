# 0.3 验证记录 · 2026-10-18

0.2 的网页使用另一套 JavaScript 界面和八个示例音色，未实现所要求的固件仿真；这些旧版功能和测试不能作为原始音色对齐的证据。0.3 改为共享 C 固件的 WASM 宿主，并恢复原始六个 JSON。未连接或刷写实体 FM-1。

| 项目 | 本轮验证结果 |
| --- | --- |
| 原始程序 | 六个 JSON 与锁定 OpenIFW 源文件 SHA-256 相同，名字、作者、ProgramIndex 和数值未改写 |
| 实际预设参数 | 1098 项核对，其中八槽矩阵 192 字段、四包络 120 字段 |
| C / WASM 一致性 | 135 个相同 API 操作，77 次渲染，9,576,952 字节 PCM、真实 LCD、patch 与演奏状态完全相同 |
| 完整原始音色对照 | 6 × 干／湿各 4 秒，直接参照未修改的 OpenIFW JS；包含持续音、重复音 Legato、松键回退、气息、弯音、Glide 和 release |
| 干声最大 RMSE | 6.43313472e-05，保留 RMSE < 0.0001 与峰值 < 0.004 门限 |
| 含效果最大 RMSE | 0.000892345464；单独测量，未宣称效果器逐采样一致 |
| 包络最大电平差 | 1.18809025e-05（满幅 1）；有 2 个 16 采样抽样点的阶段边界差异，保留数值报告 |
| 音高状态最大差 | 8.78943595e-05 半音 |

| 真机实时 CPU / 音频 / 刷写 | 未测；编译成功和宿主仿真不代替真机验证 |

本轮修正了四项实际问题：负数 Q15 反馈的残留直流、Note 双极性调制的过早除法、滑音系数／动态速度精度，以及滑音结束仍差一个定点单位。最后一项会让持续音相位继续偏移；修正后长音色对照通过既有干声门限。屏幕十进制显示改用舍入，ARP 跳转更正为 AMP，矩阵加入原始音色使用的 Pitch Bend (+-) 等来源。

效果器仍有明确硬件简化：两个 Delay 为 22.05 kHz / Q15 / 最长 1 秒；Reverb 缓冲为 Q15。原始 OpenIFW 的未消费字段和 Ext In 边界保留，详见 DSP_PORT.md。包络与音频的有限精度差异不等于程序参数被改写。

`factory-regression-results.json`、`firmware-wasm-results.json` 和 `factory-parameter-audit.json` 是本轮证据。`validation-v3.log` / `sanitizer-v3.log` 为本轮日志。较早的 phase2、0.2 与匿名短音色记录只用于追溯，不能代表当前界面或原始预设。成对 original-js / fixed WAV 在交付包 examples/factory-audio 中。
