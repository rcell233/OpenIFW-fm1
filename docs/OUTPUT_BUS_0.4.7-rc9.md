# 0.4.7-rc9：可旁路的输出增益与峰值管理

2026-11-01。默认启用 **LOUD**：在效果器之后提高平均电平，用左右联动限幅和峰值软削波管理强信号。**NORMAL 与 rc8 的原样输出逐采样一致。** 这是输出音量功能，不是 CPU 欠载修复，也不能保证实体设备没有爆音。

## 操作

长按 HOME 打开菜单，ALGORITHM 选 AUDIO，PRESETS 选 OUTPUT，旋钮 1 选 LOUD 或 NORMAL。到 SYS → SAVE SETUP，用 OCT+ 确认保存。退出菜单即可继续演奏。旧配置升级及新安装默认 LOUD；已保存的 NORMAL 会在重启后恢复。首次试音先调低物理 MASTER。

复用原 UI 设置区的保留字节，设置结构、CRC、用户音色和 Flash 分区不变。切换档位本身不写 Flash，也不修改或保存任何音色参数。网页和实体固件调用同一份 C 输出模块。

## 实际提高多少

原生 C 数字测量：A4、力度 110、满呼吸、物理 MASTER 对应 Q12=4096，持续 4 秒。RMS 以最终 I2S 数字满刻度为基准，不是声压或耳机输出电压。

| 出厂音色 | NORMAL / rc8 RMS | LOUD RMS | 提升 |
|---|---:|---:|---:|
| Tresure Island | −25.79 dBFS | −19.77 dBFS | 6.02 dB |
| Primer | −24.39 dBFS | −18.37 dBFS | 6.02 dB |
| Ai no Labyrinth | −26.32 dBFS | −20.30 dBFS | 6.02 dB |
| Daisy Area 2 | −20.58 dBFS | −15.28 dBFS | 5.30 dB |
| Wanna Go To Hawaii | −22.55 dBFS | −19.75 dBFS | 2.80 dB |
| JUDD-ish 2000 | −25.78 dBFS | −19.76 dBFS | 6.02 dB |

288 个音高、力度、呼吸组合的平均电平提升范围为 **0.18–6.02 dB**。强峰值多的音色会被更多限幅，因此不是所有音符都恒定提高 6 dB。额外 6 组密集演奏各 30 秒，包含连奏、分奏与尾音；总计 1,332 秒、117,482,400 个声道采样中，419 个采样进入软削波区。稳态 LOUD 的最大输出为 Q15=30720，对应现有 I2S 标定的 0.46875 满刻度；没有整数溢出。

## 处理方式和代价

顺序为：原合成器及全部 FX → 物理 MASTER 与输出增益 → 左右联动峰值限幅 → 软峰值保护 → 原 I2S / USB 转换。

- NORMAL 直接使用未修改的 `output_level.h`，保留 rc8 的 ×2 增益、舍入和边界。
- LOUD 使用 ×4 前置驱动，即相对 rc8 再加 6.02 dB；中间保留 int32 余量，不先截成 Q15。
- 检测左右声道绝对值的较大者，同一增益作用于左右。参考 Felucca 的快速攻击／指数释放结构：每采样按差值的 1/4 跟随上升峰值，按 1/4096 回落到阈值。44.1 kHz 下释放时间常数约 93 ms，阈值 24576/32768。
- 增益用 513 项 Q14 倒数表加线性插值计算，占 1026 字节；逐帧路径不调用浮点、对数、指数或变量除法。完整包中的处理函数为 554 字节，放在既有音频 RAM 区；链接脚本未改。
- 软削波在 ±28672 以下严格线性，在峰值区用二次曲线平滑到 ±30720。没有 lookahead 延迟；这不是模拟域或插值后的 true-peak 限幅器。
- 只有用户手动切换 OUTPUT 档位时，档位混合系数经过 256 帧控制过渡，约 5.8 ms。音符、预设、Panic、欠载均不触发该过渡；没有恢复 rc6 的换音处理、欠载淡出或丢帧。

限幅和软削波会改变强信号的动态、波形与谐波，不能称为完全透明。数字正弦测试中，低电平逐采样恰好为原输入 ×4，约 0.01% THD+N 来自原 Q15 正弦量化；持续过驱动时，100 Hz 测得 0.82%–1.24%，43.07 Hz 测得 1.83%–2.69%。这是刻意超过阈值的压力测试，包含限幅增益变化，不能直接当成出厂音色或实体 DAC 的失真指标。需要原动态时选择 NORMAL。

这个输出级不能修复上游 FX 已产生的削波，也不会提高既有噪声相对信号的信噪比。Q23 混响降噪实现保持不变。

## 计算开销

运行实际 `.fwsc` 的 pi32v2 指令，与可重复构建且 SHA 一致的 rc8 包比较。下表是 A4 持续音时每 256 帧 DSP 块的**中位模型耗时**，包含新增输出处理。

| 音色 | rc8 | rc9 LOUD | 增加 |
|---|---:|---:|---:|
| Tresure | 3063.54 µs | 3121.50 µs | 1.89% |
| Primer | 2169.25 µs | 2227.13 µs | 2.67% |
| Ai | 2438.29 µs | 2496.17 µs | 2.37% |
| Daisy | 2962.83 µs | 3020.46 µs | 1.94% |
| Wanna | 2388.96 µs | 2454.96 µs | 2.76% |
| Judd | 2130.33 µs | 2188.25 µs | 2.72% |

密集演奏沿用 rc8 对照脚本：Daisy 每 25 ms 换音、保持 16 ms，P99 从 3134.38 增至 3198.96 µs；Tresure 每 32 ms 换音、保持 45 ms，P99 从 3193.83 增至 3254.13 µs。所有本轮模型场景的 UND / XRUN / DMA 均为 0。

这些是未校准的指令比较：CPU 240 MHz、普通指令 1 周期、除法 48 周期、SPI 外设时钟假定 60 MHz；没有真实 cache、Flash、总线或连接的 USB 主机模型。**不能换算成实机 CPU 使用率，也不能据此保证实机不欠载。** 新增输出功能消耗少量运算预算，保留此前 rc8 的精确 DSP 优化。
