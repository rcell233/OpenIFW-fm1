# 0.4.7-rc4：最终输出增加约 6 dB

**修复用户反馈的 MASTER 需要接近最大才够响的问题：效果器之后的最终输出统一放大 ×2（+6.02 dB）。网页 Demo 和硬件使用同一段输出代码。首次试音请先调低 MASTER。**

安装：[Install 0.4.7-rc4](https://rcell233.github.io/OpenIFW-fm1/install/?candidate=0.4.7-rc4&v=0.4.7-rc4)。[下载 .fwsc](https://rcell233.github.io/OpenIFW-fm1/firmware/OpenIFW-FM1-0.4.7-rc4.fwsc)。

SHA-256：`661c57a11f60a3824d0f10a205f38c8a35974925ddd82e545fae20b5ebc5918e`。固件身份 `FM-1_982`，诊断版本 `40704`，包大小 610,161 字节。实机声音与实际声压仍待用户验收。

## 改动范围

上轮 [与其他固件的电平对比](OUTPUT_LEVEL_0.4.7-rc3.md) 已确认：MASTER 平方曲线和 DAC 的约 6 dB 余量与 Dinghy / Felucca / Ghoulbox 一致，主要差别是进入 MASTER 前的音色输出较低。出厂 MasterLevel 多数已经最大。

`output_level.h` 将校准增益和 MASTER 合并为一次整数乘法：原先右移 12 位，现在右移 11 位。依旧在两者之后限制到 ±32767，再按原值乘 128 送 I2S；USB 音频也获得同一音量修正。MASTER 调低时不会先被 ×2 的中间值削波。没有增加滤波器、压缩器、逐采样除法或额外缓冲。

四 OSC、FM、硬同步、主滤波器 / Filter3、包络、LFO、矩阵、单音、重复音、Legato、气息映射及全部原始预设参数不变；rc3 的半速混响和音频队列调度也不变。此增益不会改变效果器内部的驱动电平。仪表的原始 DSP peak / clip 计数继续位于最终输出校准之前。

## 软件验证

- **288 个出厂场景**：六个预设 × 八个音高 × 力度 110/127 × breath 25%/50%/100%，每个 4 秒。放大前的全部测量与 rc3 原始证据精确相等；放大后的峰值和 RMS 为原来 ×2，触及输出边界的采样数为 0。最高输出峰值 0.957886 Q15，仍保留约 0.37 dB 的 Q15 余量，之后还有原有 DAC 缩放余量。
- **600 秒长场景**：每个预设 100 秒，包括低音 / 高音各持续 20 秒、长释放、重叠音、重复音及呼吸变化，输出边界采样数均为 0。
- **524,288 个算术边界检查**：遍历完整有符号 16 位 PCM 与八个 MASTER 值，验证静音、单调性、32 位乘法范围和饱和边界；ASan / UBSan 通过。
- **WASM 新旧输出对比**：相同生产 DSP 分别使用 ×2 和 ×1 最终输出，18 个场景、2,764,800 个声道采样、81,000 个参数 / 音乐状态检查。音符、包络、Legato 和参数精确一致；输出为原来的 ×2，合并 MASTER 舍入的差别最多一个输出 LSB。
- **既有回归**：166 组定点引擎回归、332 个 PCM / 状态文件、166 组生产音乐状态、158 组干声、原有 12 组历史音频、原生 C / WASM 字节一致性、UI、存储、安装器 134 项检查及 sanitizer 均通过。历史音频使用显式的未发布全速效果 / ×1 输出参考，生产 ×2 输出由独立对比验证，未重写旧 goldens。
- **目标固件指令模型**：实际执行打包的 pi32v2 指令，Daisy 持续 A4 运行 32 秒，UND / XRUN / DMA late 都为 0；DSP P99 3.327 ms、最大 3.354 ms，UI 刷新间隔 P95 50 ms，主循环最大服务间隔 1 ms。正常启动超过 30 秒后 boot pending 清零；OCT− 开机进入原有 USB RESCUE。

目标模型按 240 MHz、普通指令 1 周期、除法 48 周期、SPI 60 MHz 估算，不模拟真实 Flash / cache / 总线等待和 USB 主机，**不是实机 CPU 性能测量**。资源用量与 rc3 相同：data+bss 81,712 B，pool 279,272 B，RAM code 19,064 B；app 减少 16 字节至 268,348 B。输入 / 时间 / ISR 原始 HAL 和链接脚本的 SHA-256 不变。

完整数据与校验值见 [验证证据](evidence/output-gain-0.4.7-rc4.json)。上述无削波结论覆盖这些测试场景，不能扩展为任意用户编辑或任何模拟播放音量都绝无失真；现有最终饱和保护继续避免数值回绕。

## 安装与回退

新版默认安装入口与显式 `candidate=0.4.7-rc4` 指向同一个正常固件包。旧 rc3 包逐字节保留，可通过 [回退到 0.4.7-rc3](https://rcell233.github.io/OpenIFW-fm1/install/?recovery=0.4.7-rc3&v=0.4.7-rc4) 恢复原输出音量。rc2 和更早的恢复入口保留。
